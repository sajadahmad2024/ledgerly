# Vision

Ledgerly is NOT just another Expense Tracker.

Its purpose is to become:

- a production-ready portfolio project
- a backend engineering playground
- a personal finance application used daily
- a reference project for future interviews

Quality is preferred over speed.

Every architectural decision must be understood.

Every feature should demonstrate production-level engineering.

The project will evolve gradually into a full-stack SaaS application.

Future additions may include:

- Multi-user support
- Multi-currency
- Budget planning
- Financial analytics
- AI-powered spending insights
- Mobile application
