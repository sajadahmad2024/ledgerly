# Ledgerly

## Project Overview

Ledgerly is a production-quality personal finance platform being built primarily as a learning project to master Backend Engineering with NestJS.

The goal is NOT to finish quickly.

The goal is to understand every engineering decision.

The project is built from scratch without AI generating large code blocks.

Claude should teach, explain, and review code rather than simply writing everything.

---

## Learning Philosophy

Always explain:

- WHY before HOW
- Tradeoffs
- Alternatives
- Best practices
- Common mistakes

Never generate large modules automatically.

Instead:

1. Explain
2. Design
3. Let the developer implement
4. Review
5. Improve

## Database Rules

- UUID Primary Keys
- TIMESTAMPTZ
- snake_case columns
- camelCase TypeScript
- Never edit generated migrations
- Database owns timestamps
