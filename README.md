# Ledgerly 💰

> Your Personal Financial Operating System

Ledgerly is a modern full-stack expense tracking application designed to help users manage their personal finances, monitor spending habits, and gain actionable financial insights.

This project is being built as a long-term learning and production-ready application using modern backend and frontend technologies.

---

## 🎯 Project Goals

- Learn and master NestJS through a real-world project.
- Build a scalable backend following production-grade architecture.
- Build a modern Next.js frontend.
- Deploy the application and use it for daily personal expense tracking.
- Continuously improve the application with advanced financial features.

---

## 🚀 Tech Stack

### Backend

- NestJS
- TypeScript
- PostgreSQL
- Drizzle ORM
- JWT Authentication
- Passport
- Swagger
- class-validator

### Frontend (Coming Soon)

- Next.js
- TypeScript
